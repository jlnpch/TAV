# Projet TAV

Ce dépôt rassemble le rapport, les codes et les résultats (graphiques, images, extraits audio...) du projet de TAV (Traitement des données Audio-Visuelles).

## Contenu

Le projet approfondi 4 TP vus en cours : 

* **TP5 : Restauration d’images**
* **TP7 : Photomontage**
* **TP10 : Manipulation de signaux audionumériques**
* **TP12 : Séparation de Source**

Les TPs 5,7 et 10 sont traités en MATLAB tandis que le TP 12 est un notebook python utilisant Keras et Tensorflow pour l'entrainement d'un réseau de neurones
Tout les codes réalisés pour ce projet sont dans /codes tandis que les résultats produits par ces codes sont dans /resultats.
